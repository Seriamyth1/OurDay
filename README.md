# OurDay

OurDay is a free, Java-based customizable calendar application with daily, weekly, and monthly views.

## Description

OurDay is a customizable desktop calendar application designed to make schedule management easier, more flexible, and more enjoyable. 
It helps users organize daily responsibilities, upcoming tasks, appointments, deadlines, and important events through a clean calendar 
experience that can be personalized to match each user’s preferences. 

Key features include:
Daily, weekly, and monthly views so users can review their schedules at different levels of detail
Reminders for upcoming tasks and events
Flexible calendar organization and management
Customizable backgrounds and themes

All calendar data is saved locally, so OurDay can be used without an internet connection.

## Tech Stack

* **Language:** Java
* **User Interface:** JavaFX with CSS for customizable user interface
* **Local Storage:** SQLite
* **Build Tool:** Maven
* **Testing:** JUnit 5
* **Version Control:** Git and GitHub
